InfoPrice Design System

Adocao em React

O DS InfoPrice e uma biblioteca CSS framework-agnostic. Para usar em React, basta aplicar as classes via className no JSX. Nao requer rewrite, nao introduz dependencias e convive com qualquer stack (RSuite, MUI, componentes proprios). Este guia mostra os padroes mais comuns.

Conceito

O DS expoe duas coisas: tokens CSS (variaveis) e classes utilitarias no padrao BEM. Ambos sao framework-agnostic.

Tokens — use no style ou em CSS-in-JS

jsx 
// Inline style
<div style={{ color: 'var(--color-blue-500)', padding: 'var(--space-4)' }}>
  Texto azul
</div>

// styled-components / emotion
const Card = styled.div`
  background: var(--color-white);
  border-radius: var(--radius-md);
  box-shadow: var(--shadow-elevation);
`;

Classes — use via className

jsx 
<button className="btn btn--primary btn--large">
  Salvar
</button>

<span className="badge badge--filled badge--green">Ativo</span>
check_circle
Compativel com qualquer biblioteca Voce pode misturar com RSuite, MUI, Ant Design ou componentes proprios. As classes do DS apenas adicionam estilos — nao quebram nada.

Botoes

Sistema baseado no Figma DS InfoPrice. 3 tipos (primary, secondary, link), cada um com seus temas, em 4 tamanhos (large default, medium, small, xsmall) e 4 estados (default, hover, active, disable).

Componente reutilizavel (compatible com todos os tipos/temas/sizes)

jsx 
import clsx from 'clsx';

/**
 * Button — sistema oficial do DS InfoPrice (baseado no Figma)
 *
 * @param type    'primary' | 'secondary' | 'link'   (default: 'primary')
 * @param theme   tema dependente do type:
 *                  primary:   undefined | 'ghost'
 *                  secondary: undefined (=blue) | 'red' | 'gray' | 'white'
 *                  link:      undefined (=blue) | 'gray'
 * @param size    'large' (default) | 'medium' | 'small' | 'xsmall'
 * @param active  forca estado active (alem do :active nativo)
 */
export function Button({
  type = 'primary',
  theme,
  size,
  active,
  className,
  children,
  ...props
}) {
  return (
    <button
      className={clsx(
        'btn',
        `btn--${type}`,
        theme && `btn--${theme}`,
        size && `btn--${size}`,
        active && 'is-active',
        className
      )}
      {...props}
    >
      {children}
    </button>
  );
}

Uso — Primary

jsx 
// Filled (default — CTA principal)
<Button type="primary">Confirmar</Button>

// Ghost (transparente com border azul)
<Button type="primary" theme="ghost">Cancelar</Button>

// Disabled
<Button type="primary" disabled>Salvar</Button>

Uso — Secondary (4 temas)

jsx

Twin button — split (acao + drop)

Twin e um botao "split": a metade esquerda dispara a acao primaria, a direita abre um menu/dropdown. As duas metades sao <button> independentes, divididas por 1px branco. Hover/active afetam apenas a metade que recebe o mouse. Componente <ButtonTwin> abaixo encapsula o markup.

jsx 
import clsx from 'clsx';

export function ButtonTwin({
  size,
  disabled,
  onMainClick,
  onDropClick,
  dropAriaLabel = 'Mais opcoes',
  children,
}) {
  return (
    <div className={clsx('btn-twin', size && `btn-twin--${size}`, disabled && 'is-disabled')}>
      <button
        type="button"
        className="btn-twin__main"
        onClick={onMainClick}
        disabled={disabled}
      >
        {children}
      </button>
      <button
        type="button"
        className="btn-twin__drop"
        aria-label={dropAriaLabel}
        onClick={onDropClick}
        disabled={disabled}
      >
        <span className="material-icons-outlined">keyboard_arrow_down</span>
      </button>
    </div>
  );
}

Uso — Twin

jsx 
// Acao primaria + dropdown de variantes
<ButtonTwin
  onMainClick={() => salvar()}
  onDropClick={() => setMenuAberto(true)}
>
  Salvar
</ButtonTwin>

// 4 tamanhos: large (default), medium, small, xsmall
<ButtonTwin size="medium" onMainClick={...} onDropClick={...}>
  Exportar
</ButtonTwin>

// Disabled (ambas as metades)
<ButtonTwin disabled>Indisponivel</ButtonTwin>
info
Specs do Figma (auto-aplicados via CSS) Primary & Secondary: Open Sans Bold UPPERCASE, border-radius 4px. Link: Open Sans Regular, sem uppercase, sem padding/border, icone opcional escalonando com o tamanho (20/16/12/10px). Twin: usa estilo Primary blue, divisor de 1px branco entre as duas metades; cada metade clicavel separadamente. Transicao de cor: Blue 400 → 600 (hover) → 700 (active); Gray 500 → 600 → 700. Disabled: opacity 0.4.

Tags & Badges

Padronize ambos com componentes utilitarios. Os modificadores de cor (--blue, --green, --orange, --red, --gray) e tema (--filled / --ghost) viram props.

jsx 
function Tag({ color = 'gray', theme = 'filled', size, icon, children }) {
  const classes = [
    'tag',
    `tag--${theme}`,
    `tag--${color}`,
    size && `tag--${size}`,
  ].filter(Boolean).join(' ');
  return (
    <span className={classes}>
      {icon && <span className="material-icons-outlined tag__icon">{icon}</span>}
      {children}
    </span>
  );
}

// Uso
<Tag color="green">Ativo</Tag>
<Tag color="red" theme="ghost" icon="error">Bloqueado</Tag>

Form fields

Estrutura padrao: wrapper .form-field com label, input-wrapper e helper. Combine com state do React para erro e valor controlado.

jsx 
function FormField({
  label,
  required,
  error,
  helper,
  size,
  prefix,
  suffix,
  ...inputProps
}) {
  const wrapperClasses = [
    'form-field',
    size && `form-field--${size}`,
    error && 'is-error',
    inputProps.disabled && 'is-disabled',
  ].filter(Boolean).join(' ');

  return (
    <div className={wrapperClasses}>
      <label className="form-field__label">
        {label}
        {required && <span className="form-field__required">*</span>}
      </label>
      <div className="form-field__input-wrapper">
        {prefix && <span className="form-field__prefix">{prefix}</span>}
        <input className="form-field__input" {...inputProps} />
        {suffix && <span className="form-field__suffix">{suffix}</span>}
      </div>
      {(error || helper) && (
        <span className="form-field__helper">{error || helper}</span>
      )}
    </div>
  );
}

// Uso
const [email, setEmail] = useState('');
const [error, setError] = useState('');

<FormField
  label="Email"
  required
  type="email"
  value={email}
  onChange={(e) => setEmail(e.target.value)}
  error={error}
  helper="Usaremos para contato"
/>

<FormField
  label="Preco"
  prefix="R$"
  type="text"
  value="12,49"
/>

classNames condicionais

Use a biblioteca clsx (ou classnames) para compor classes baseadas em estado. Mais limpo que template literals com falsy filtering.

jsx 
// npm install clsx
import clsx from 'clsx';

function Switch({ checked, disabled, label, onChange }) {
  return (
    <label
      className={clsx('switch', {
        'is-checked': checked,
        'is-disabled': disabled,
      })}
      onClick={() => !disabled && onChange(!checked)}
      role="switch"
      aria-checked={checked}
      tabIndex={disabled ? -1 : 0}
    >
      <span className="switch__track">
        <span className="switch__thumb"></span>
      </span>
      {label && <span className="switch__label">{label}</span>}
    </label>
  );
}

Switch, Radio e Checkbox

Os 3 controles usam BEM compativel com input nativo. Switch precisa de JS para toggle (nao tem input por baixo). Radio e Checkbox usam input invisivel + estilizacao.

Switch (sem input — controlado por state)

jsx 
function Switch({ checked, onChange, disabled, size, label }) {
  const handleToggle = () => !disabled && onChange(!checked);

  return (
    <label
      className={clsx('switch', {
        [`switch--${size}`]: size,
        'is-checked': checked,
        'is-disabled': disabled,
      })}
      role="switch"
      aria-checked={checked}
      tabIndex={disabled ? -1 : 0}
      onClick={handleToggle}
      onKeyDown={(e) => {
        if (e.key === ' ' || e.key === 'Enter') {
          e.preventDefault();
          handleToggle();
        }
      }}
    >
      <span className="switch__track">
        <span className="switch__thumb"></span>
      </span>
      {label && <span className="switch__label">{label}</span>}
    </label>
  );
}

Checkbox (com input nativo)

jsx 
function Checkbox({ checked, indeterminate, onChange, label, helper }) {
  const ref = useRef();
  useEffect(() => {
    if (ref.current) ref.current.indeterminate = !!indeterminate;
  }, [indeterminate]);

  return (
    <label className={clsx('checkbox', { 'is-half': indeterminate })}>
      <input
        ref={ref}
        type="checkbox"
        className="checkbox__input"
        checked={checked}
        onChange={(e) => onChange(e.target.checked)}
      />
      <span className="checkbox__box"></span>
      <div className="checkbox__content">
        <span className="checkbox__label">{label}</span>
        {helper && <span className="checkbox__helper">{helper}</span>}
      </div>
    </label>
  );
}

Modal

Use useState para controlar abertura, useEffect para ESC e backdrop, e createPortal para renderizar fora da hierarquia.

jsx 
import { createPortal } from 'react-dom';

function Modal({ open, onClose, title, size, children, footer }) {
  // ESC fecha
  useEffect(() => {
    if (!open) return;
    const handler = (e) => e.key === 'Escape' && onClose();
    document.addEventListener('keydown', handler);
    return () => document.removeEventListener('keydown', handler);
  }, [open, onClose]);

  return createPortal(
    <div
      className={clsx('modal-backdrop', { 'is-open': open })}
      onClick={(e) => e.target === e.currentTarget && onClose()}
    >
      <div className={clsx('modal', size && `modal--${size}`)}>
        <div className="modal__header">
          <span className="modal__title">{title}</span>
          <button className="modal__close" onClick={onClose} aria-label="Fechar">
            <span className="material-icons-outlined">close</span>
          </button>
        </div>
        <div className="modal__body">{children}</div>
        {footer && <div className="modal__footer">{footer}</div>}
      </div>
    </div>,
    document.body
  );
}

// Uso
function MyComponent() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <button className="btn btn--primary" onClick={() => setOpen(true)}>
        Abrir modal
      </button>
      <Modal
        open={open}
        onClose={() => setOpen(false)}
        title="Confirmar acao"
        footer={
          <>
            <button className="btn btn--secondary-ghost" onClick={() => setOpen(false)}>
              Cancelar
            </button>
            <button className="btn btn--primary">Confirmar</button>
          </>
        }
      >
        Voce esta prestes a aplicar 15 precos. Continuar?
      </Modal>
    </>
  );
}

Toast

Padrao recomendado: provider + hook. Um ToastProvider no topo da app gerencia a fila, e useToast dispara de qualquer lugar.

jsx 
const ToastContext = createContext();

export function ToastProvider({ children }) {
  const [toasts, setToasts] = useState([]);

  const show = useCallback((message, options = {}) => {
    const id = Date.now() + Math.random();
    const toast = {
      id,
      variant: options.variant || 'info',
      title: options.title,
      duration: options.duration ?? 4000,
      message,
    };
    setToasts((t) => [...t, toast]);
    if (toast.duration) {
      setTimeout(() => dismiss(id), toast.duration);
    }
  }, []);

  const dismiss = useCallback((id) => {
    setToasts((t) => t.filter((x) => x.id !== id));
  }, []);

  const iconFor = {
    info: 'info', success: 'check_circle',
    warning: 'warning', error: 'error',
  };

  return (
    <ToastContext.Provider value={{ show, dismiss }}>
      {children}
      <div className="toast-container">
        {toasts.map((t) => (
          <div key={t.id} className={`toast toast--${t.variant}`}>
            <span className="material-icons-outlined toast__icon">{iconFor[t.variant]}</span>
            <div className="toast__content">
              {t.title && <span className="toast__title">{t.title}</span>}
              <span className="toast__body">{t.message}</span>
            </div>
            <button className="toast__close" onClick={() => dismiss(t.id)} aria-label="Fechar">
              <span className="material-icons-outlined">close</span>
            </button>
          </div>
        ))}
      </div>
    </ToastContext.Provider>
  );
}

export const useToast = () => useContext(ToastContext);

// Uso
const { show } = useToast();
show('Precos aplicados', { variant: 'success', title: '15 produtos' });

Dropdowns (SelectPicker, Filtro chip, Context menu)

Padrao: state controla isOpen; useEffect registra listener de click-outside; ESC fecha.

jsx 
function useDropdown() {
  const [isOpen, setIsOpen] = useState(false);
  const ref = useRef(null);

  useEffect(() => {
    if (!isOpen) return;
    const onClick = (e) => {
      if (ref.current && !ref.current.contains(e.target)) setIsOpen(false);
    };
    const onKey = (e) => e.key === 'Escape' && setIsOpen(false);
    document.addEventListener('mousedown', onClick);
    document.addEventListener('keydown', onKey);
    return () => {
      document.removeEventListener('mousedown', onClick);
      document.removeEventListener('keydown', onKey);
    };
  }, [isOpen]);

  return { isOpen, setIsOpen, ref };
}

function SelectPicker({ options, value, onChange, placeholder }) {
  const { isOpen, setIsOpen, ref } = useDropdown();
  const selected = options.find((o) => o.value === value);

  return (
    <div className="select-picker" ref={ref}>
      <button
        className={clsx('select-picker__trigger', { 'is-open': isOpen })}
        onClick={() => setIsOpen(!isOpen)}
      >
        <span className={selected ? '' : 'select-picker__placeholder'}>
          {selected ? selected.label : placeholder}
        </span>
        <span className="material-icons-outlined select-picker__chevron">keyboard_arrow_down</span>
      </button>
      <div className={clsx('select-picker__dropdown', { 'is-open': isOpen })}>
        <div className="select-picker__list">
          {options.map((o) => (
            <div
              key={o.value}
              className={clsx('select-picker__item', { 'is-selected': o.value === value })}
              onClick={() => { onChange(o.value); setIsOpen(false); }}
            >
              {o.label}
            </div>
          ))}
        </div>
      </div>
    </div>
  );
}
