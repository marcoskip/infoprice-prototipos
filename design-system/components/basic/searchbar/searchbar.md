# Searchbar

Campo de busca standalone com ícone, botão clear (aparece quando há texto), loading e dropdown opcional de sugestões. Espelha o padrão do <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.filtro-dropdown__search</code> mas funciona fora de filtros. 3 sizes (small, medium, large).

## Markup canônico

Veja `searchbar.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `searchbar.css` para as classes CSS deste componente.
