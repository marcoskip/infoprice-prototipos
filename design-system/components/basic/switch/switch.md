# Switch

Toggle on/off com 3 estados (off, on, half) e 3 tamanhos (small, medium, large). Use para configurações booleanas. Estado <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.is-half</code> indica seleção parcial em listas.

## Markup canônico

Veja `switch.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `switch.css` para as classes CSS deste componente.
