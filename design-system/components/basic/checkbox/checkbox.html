Checkbox

Quando usar: para seleção múltipla independente (várias caixas marcáveis ao mesmo tempo) ou como sim/não opcional (uma única caixa, marcação não obrigatória).
Quando NÃO usar: para escolha única obrigatória entre opções, use Radio. Para liga/desliga binário em configurações, use Switch.

Seleção múltipla ou opcional. 3 estados (off, on, half) e 3 variantes (caixa, + label, + label + complementar).
