Botões

Quando usar: ações principais e secundárias do conteúdo da página (Salvar, Cancelar, Excluir, Saiba mais). 3 tipos: primary (ação principal), secondary (alternativa ou destrutiva), link (textual sem moldura).
Quando NÃO usar: para botão com dropdown anexado, use Twin button. Para toolbar de ícones no Cabeçalho de resultados, use Botões compostos. Para áreas de navegação estrutural, use Nav button. Para chips em filtros, use Filtro chips.

Sistema baseado na referência oficial do Figma. 3 tipos (primary, secondary, link), cada um com seus temas, em 4 tamanhos (large default, medium, small, xsmall) e 4 estados (default, hover, active, disable). Tipografia Open Sans Bold UPPERCASE.

Primary — filled e ghost 
<!-- Primary filled (default) -->
<button class="btn btn--primary">Confirmar</button>

<!-- Primary ghost (transparente com border azul) -->
<button class="btn btn--primary btn--ghost">Cancelar</button>

<!-- Estados: default | :hover | :active (ou .is-active) | :disabled -->
Secondary — 4 temas (blue, red, gray, white) 
<!-- Secondary blue (default) -->
<button class="btn btn--secondary">Salvar</button>

<!-- Secondary red (ações destrutivas: Excluir, Cancelar pedido) -->
<button class="btn btn--secondary btn--red">Excluir</button>

<!-- Secondary gray (ação neutra forte) -->
<button class="btn btn--secondary btn--gray">Arquivar</button>

<!-- Secondary white (fundo claro com border cinza) -->
<button class="btn btn--secondary btn--white">Cancelar</button>
Link — blue e gray (com ícone, 4 tamanhos) 
<!-- Link blue (default), icone opcional a esquerda -->
<button class="btn btn--link">
  <span class="material-icons-outlined">open_in_new</span>
  Saiba mais
</button>

<!-- Link gray (alternativo neutro) -->
<button class="btn btn--link btn--gray">Cancelar</button>

<!-- 4 tamanhos: large (default), medium, small, xsmall -->
<button class="btn btn--link btn--medium">...</button>
<button class="btn btn--link btn--small">...</button>
<button class="btn btn--link btn--xsmall">...</button>

<!-- Specs (Open Sans Regular, sem uppercase, sem padding/border) -->
<!-- Large:  16/22, gap 8px,  icone 20px -->
<!-- Medium: 14/20, gap 6px,  icone 16px -->
<!-- Small:  12/18, gap 4px,  icone 12px -->
<!-- Xsmall: 10/16, gap 2px,  icone 10px -->
4 Tamanhos (large default, medium, small, xsmall) 
<!-- Large e o padrão se nenhum size for declarado -->
<button class="btn btn--primary btn--large">...</button>
<button class="btn btn--primary btn--medium">...</button>
<button class="btn btn--primary btn--small">...</button>
<button class="btn btn--primary btn--xsmall">...</button>

<!-- Specs (Open Sans Bold UPPERCASE) -->
<!-- Large:  16px / 22px line-height, padding 10/16 -->
<!-- Medium: 14px / 20px line-height, padding 8/12   -->
<!-- Small:  12px / 18px line-height, padding 6/10   -->
<!-- Xsmall: 10px / 16px line-height, padding 4/8    -->
Com ícone (left, right ou ambos) 
<!-- Icone a esquerda -->
<button class="btn btn--primary">
  <span class="material-icons-outlined">save</span>
  Salvar
</button>

<!-- Icone a direita -->
<button class="btn btn--secondary btn--white">
  Exportar
  <span class="material-icons-outlined">file_download</span>
</button>
Twin — botão split (ação + drop) 
<!-- Twin: ação primaria a esquerda + drop a direita -->
<div class="btn-twin">
  <button class="btn-twin__main" onclick="salvar()">Salvar</button>
  <button class="btn-twin__drop" aria-label="Mais opções" onclick="abrirMenu()">
    <span class="material-icons-outlined">keyboard_arrow_down</span>
  </button>
</div>

<!-- 4 tamanhos: large (default), medium, small, xsmall -->
<div class="btn-twin btn-twin--medium">...</div>
<div class="btn-twin btn-twin--small">...</div>
<div class="btn-twin btn-twin--xsmall">...</div>

<!-- Disabled (twin inteiro ou metade individual) -->
<div class="btn-twin is-disabled">...</div>

<!-- Specs -->
<!-- Cada metade clicavel separadamente — main dispara a ação,  -->
<!-- drop abre menu/dropdown. Divisor: 1px white solid.         -->
<!-- Hover/active afetam apenas a metade hovered.               -->
Quando usar Twin button: para uma ação primary blue com dropdown anexado para variações da ação (ex: Salvar + escolher modo). Split em duas metades clicáveis: main (ação) + drop (abre menu).
Quando NÃO usar: para a ação "Aplicar preço" use o componente Aplicar preço (verde, especializado). Para botão simples sem dropdown, use Button. Para toolbar icon-only, use Botões compostos.
