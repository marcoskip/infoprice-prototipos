# Botões

Sistema baseado na referência oficial do Figma. <strong>3 tipos</strong> (primary, secondary, link), cada um com seus temas, em <strong>4 tamanhos</strong> (large default, medium, small, xsmall) e <strong>4 estados</strong> (default, hover, active, disable). Tipografia Open Sans Bold UPPERCASE.

## Markup canônico

Veja `botoes.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `botoes.css` para as classes CSS deste componente.
