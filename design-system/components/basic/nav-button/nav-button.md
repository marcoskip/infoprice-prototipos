# Nav button

Botão de ação usado em áreas de navegação de página (cabeçalho de feature, barra lateral, breadcrumb). Diferente do <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.title-btn</code> (compacto, com chevron de dropdown): nav-button é mais flexível — suporta texto, ícone, icon-only e estado ativo. 3 sizes.

## Markup canônico

Veja `nav-button.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `nav-button.css` para as classes CSS deste componente.
