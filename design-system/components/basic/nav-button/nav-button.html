Nav button

Quando usar: em áreas de navegação ESTRUTURAL da página (cabeçalho de feature, sub-nav, breadcrumb, barra lateral). Suporta texto, ícone, icon-only e estado ativo.
Quando NÃO usar: para ações principais do conteúdo (Salvar, Cancelar), use Button. Para botões compactos com chevron na Title bar, use .title-btn. Para toolbar do Cabeçalho de resultados, use Botões compostos.

Botão de ação usado em áreas de navegação de página (cabeçalho de feature, barra lateral, breadcrumb). Diferente do .title-btn (compacto, com chevron de dropdown): nav-button é mais flexível — suporta texto, ícone, icon-only e estado ativo. 3 sizes.

Icon-left (variante padrão) 
<button class="nav-button nav-button--icon-left">
  <span class="material-icons-outlined">home</span>
  Inicio
</button>

<!-- Estados:    padrão | .is-active | disabled -->
<!-- Tamanhos:   .nav-button--small | (default) | .nav-button--large -->
Icon-right e sem ícone 
<!-- Icon-right: span depois do texto -->
<button class="nav-button nav-button--icon-right">
  Proximo
  <span class="material-icons-outlined">arrow_forward</span>
</button>

<!-- Sem ícone: omitir o span -->
<button class="nav-button">Apenas texto</button>
Icon-only 
<button class="nav-button nav-button--icon-only" aria-label="Voltar">
  <span class="material-icons-outlined">arrow_back</span>
</button>

<!-- Sempre incluir aria-label para acessibilidade quando icon-only -->
Tamanhos

<button class="nav-button"> ... </button>          <!-- medium = default -->
