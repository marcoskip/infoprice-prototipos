Radio

Quando usar: para UMA escolha obrigatória entre opções pré-definidas mutuamente exclusivas (ex: "Aplicar preço sugerido" vs "Aplicar preço vigente").
Quando NÃO usar: para escolha opcional ou múltipla, use Checkbox. Para liga/desliga binário em configurações, use Switch.

Seleção única obrigatória em um grupo. 3 variantes: only radio, radio + label, radio + label + texto complementar.

Variantes 
<!-- Only radio -->
<label class="radio">
  <input type="radio" name="grupo" class="radio__input" />
  <span class="radio__circle"></span>
</label>

<!-- Radio + label -->
<label class="radio">
  <input type="radio" name="grupo" class="radio__input" checked />
  <span class="radio__circle"></span>
  <div class="radio__content">
    <span class="radio__label">Texto</span>
  </div>
</label>

<!-- Radio + label + helper -->
<div class="radio__content">
  <span class="radio__label">Titulo</span>
  <span class="radio__helper">Texto complementar</span>
</div>
