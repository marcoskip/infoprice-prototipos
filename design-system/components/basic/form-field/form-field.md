# Form field

Input com label, helper text, prefix/suffix opcionais e estados (default, error, success, disabled). Padrão visual derivado do <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.grid__form-field</code>, mas standalone com label/helper. 4 sizes: small, medium (default), large, paragraph (textarea).

## Markup canônico

Veja `form-field.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `form-field.css` para as classes CSS deste componente.
