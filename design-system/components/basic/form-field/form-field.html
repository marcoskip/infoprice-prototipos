Form field

Input com label, helper text, prefix/suffix opcionais e estados (default, error, success, disabled). Padrão visual derivado do .grid__form-field, mas standalone com label/helper. 4 sizes: small, medium (default), large, paragraph (textarea).

Variantes básicas
Usaremos este email para contato
Código inválido — use formato AAA-000
Não é possível alterar a loja deste registro 
<!-- Basico -->
<div class="form-field">
  <label class="form-field__label">Nome do produto</label>
  <div class="form-field__input-wrapper">
    <input type="text" class="form-field__input" placeholder="Ex: ..." />
  </div>
  <span class="form-field__helper">Texto de ajuda</span>
</div>

<!-- Required -->
<label class="form-field__label">Email <span class="form-field__required">*</span></label>

<!-- Estados: padrão | .is-error | .is-success | .is-disabled -->

% 
<div class="form-field__input-wrapper">

<div class="form-field__input-wrapper">
