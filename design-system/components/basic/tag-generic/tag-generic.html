Tag (genérico)

Quando usar: etiqueta descritiva com texto obrigatório (e ícone opcional) — para rotular categorias, atributos nominais ou status com nome.
Quando NÃO usar: se for só um marcador visual sem texto (ponto colorido ou ícone isolado), use Badge.

Etiqueta com texto sempre presente (e ícone opcional). 2 temas, 5 cores, 4 tamanhos (xsmall, small, medium, large). Para indicadores apenas de ícone, use Badge.
