# Tag (genérico)

Etiqueta com texto sempre presente (e ícone opcional). 2 temas, 5 cores, 4 tamanhos (xsmall, small, medium, large). Para indicadores apenas de ícone, use Badge.

## Markup canônico

Veja `tag-generic.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `tag-generic.css` para as classes CSS deste componente.
