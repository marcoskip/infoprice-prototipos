# HourPicker

Seleção de horário com 3 colunas roláveis (hour/minute/second). Use para agendamentos e cortes de horário. Footer com botão de confirmação.

## Markup canônico

Veja `hour-picker.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `hour-picker.css` para as classes CSS deste componente.
