# SelectPicker

Combo de input + dropdown com search opcional. Use para seleção única em listas longas. Para seleção múltipla, combine com checkboxes nos itens.

## Markup canônico

Veja `select-picker.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `select-picker.css` para as classes CSS deste componente.
