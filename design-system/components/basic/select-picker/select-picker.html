SelectPicker

Quando usar: combo standalone de input + dropdown para escolher um valor dentro de uma lista (formulário, campo de entrada, contexto editorial). Suporta search.
Quando NÃO usar: para filtrar listas ou grids no contexto de filtros do IPA, use Filtro dropdowns — eles seguem 5 padrões específicos de filtragem.

Combo de input + dropdown com search opcional. Use para seleção única em listas longas. Para seleção múltipla, combine com checkboxes nos itens.
