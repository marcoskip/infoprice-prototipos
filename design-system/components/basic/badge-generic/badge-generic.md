# Badge (genérico)

Indicador compacto. 2 temas (filled, ghost), 5 cores semânticas, e 2 tamanhos (small, medium). Variante <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.badge--basic</code> é o ponto sem texto. Substitui as variantes ad-hoc <code style="font-family:'JetBrains Mono',monospace;font-size:13px">user-dropdown__badge</code> e <code style="font-family:'JetBrains Mono',monospace;font-size:13px">grid__badge-pill</code> em novos contextos.

## Markup canônico

Veja `badge-generic.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `badge-generic.css` para as classes CSS deste componente.
