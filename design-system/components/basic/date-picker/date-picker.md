# DatePicker

Calendário popup com seleção de data única ou range. Header com nav de mês, weekdays, e grid de dias. Estados: today, selected, range, disabled.

## Markup canônico

Veja `date-picker.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `date-picker.css` para as classes CSS deste componente.
