Aplicar preço

Quando usar: EXCLUSIVAMENTE para a ação "Aplicar preço" no Cabeçalho de resultados. Botão verde de destaque com chevron pra escolher a variante (sugerido vs vigente).
Quando NÃO usar: para qualquer outra ação — é um componente especializado dessa função única do IPA. Para botão genérico com dropdown, use Twin button.

Botão verde de destaque. Estrutura: aplicar-btn__main (ação) + aplicar-btn__drop (chevron com radio de variantes).

Estrutura 
<div class="aplicar-btn is-active">
  <button class="aplicar-btn__main">Aplicar preço</button>
  <button class="aplicar-btn__drop" data-dropdown="dd-aplicar">
    <span class="material-icons-outlined">keyboard_arrow_down</span>
  </button>
  <div class="composed-dropdown composed-dropdown--right" id="dd-aplicar">
    <label class="composed-dropdown__item">
      <input type="radio" name="aplicar" checked />
      <span>Aplicar preço sugerido</span>
    </label>
  </div>
</div>
