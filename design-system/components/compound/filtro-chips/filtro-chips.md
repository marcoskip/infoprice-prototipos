# Filtro chips

Pill buttons usados na seção de filtros. Variantes: simples, com chevron (dropdown), numerado, e variant clear (limpar filtros).

## Markup canônico

Veja `filtro-chips.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `filtro-chips.css` para as classes CSS deste componente.
