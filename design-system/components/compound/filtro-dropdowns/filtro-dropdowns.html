Filtro dropdowns

Quando usar: como conteúdo dos chips de filtro do IPA, para filtrar listas/grids. Escolha um dos 5 padrões documentados (search+checkbox, colar lista, selecionar todos, grupos colapsáveis, empty state).
Quando NÃO usar: para selecionar um valor único num formulário ou campo de entrada fora do contexto de filtros, use SelectPicker.

Conteúdos dos chips de filtro. Existem 5 padrões documentados: search+checkbox, search com "Colar lista", search com "Selecionar todos", grupos colapsáveis e empty state.
