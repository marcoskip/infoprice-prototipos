# Filtro dropdowns

Conteúdos dos chips de filtro. Existem 5 padrões documentados: search+checkbox, search com "Colar lista", search com "Selecionar todos", grupos colapsáveis e empty state.

## Markup canônico

Veja `filtro-dropdowns.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `filtro-dropdowns.css` para as classes CSS deste componente.
