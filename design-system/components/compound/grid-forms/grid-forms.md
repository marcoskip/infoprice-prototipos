# Grid — inputs, variação e badges

Inputs editaveis com prefix/suffix (R$, %), chips de variação up/down, badges de status (auto/editado), botão "Calcular" (link), botões de sort e preferência.

## Markup canônico

Veja `grid-forms.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `grid-forms.css` para as classes CSS deste componente.
