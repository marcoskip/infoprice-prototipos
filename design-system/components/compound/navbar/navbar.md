# Navbar (sub-navegação)

Abas horizontais para sub-navegação dentro de uma página. Diferente do header (global) e da sidebar (módulos): este é contextual a uma página/feature.

## Markup canônico

Veja `navbar.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `navbar.css` para as classes CSS deste componente.
