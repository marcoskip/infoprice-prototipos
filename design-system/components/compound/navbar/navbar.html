Navbar (sub-navegação)

Abas horizontais para sub-navegação dentro de uma página. Diferente do header (global) e da sidebar (módulos): este é contextual a uma página/feature.

Abas com ícone e estado ativo 
<div class="navbar">
  <button class="navbar__item is-active">
    <span class="material-icons-outlined">dashboard</span>
    Visão geral
  </button>
  <button class="navbar__item">
    <span class="material-icons-outlined">trending_up</span>
    Vendas
  </button>
</div>
