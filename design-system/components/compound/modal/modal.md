# Modal

Janela modal sobre backdrop escurecido. 3 tamanhos (small 400px, medium 600px, large 800px). Estrutura: header (título + close), body (conteúdo), footer (ações).

## Markup canônico

Veja `modal.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `modal.css` para as classes CSS deste componente.
