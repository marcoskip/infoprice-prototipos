Context Menu

Menu flutuante com lista de ações. Usado em right-click ou no kebab-menu. Suporta ícones, atalhos de teclado, divisores e itens destrutivos (--danger).

Estrutura 
<div class="context-menu">
  <button class="context-menu__item">
    <span class="material-icons-outlined">edit</span>
    <span>Editar</span>
    <span class="context-menu__shortcut">Ctrl+E</span>
  </button>
  <div class="context-menu__divider"></div>
  <button class="context-menu__item context-menu__item--danger">
    <span class="material-icons-outlined">delete</span>
    <span>Excluir</span>
  </button>
</div>
Demo interativa 
<!-- Trigger + menu (relative wrapper) -->
<div style="position:relative">
  <button class="nav-button nav-button--icon-only" id="myTrigger">
    <span class="material-icons-outlined">more_vert</span>
  </button>
  <div class="context-menu" id="myMenu"> ... items ... </div>
</div>

<script>
const trigger = document.getElementById('myTrigger');
const menu = document.getElementById('myMenu');
trigger.onclick = (e) => { e.stopPropagation(); menu.classList.toggle('is-open'); };
document.addEventListener('click', (e) => {
  if (!e.target.closest('#myMenu, #myTrigger')) menu.classList.remove('is-open');
});
</script>
