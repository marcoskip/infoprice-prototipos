# Context Menu

Menu flutuante com lista de ações. Usado em right-click ou no kebab-menu. Suporta ícones, atalhos de teclado, divisores e itens destrutivos (--danger).

## Markup canônico

Veja `context-menu.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `context-menu.css` para as classes CSS deste componente.
