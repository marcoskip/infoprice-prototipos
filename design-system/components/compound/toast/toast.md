# Toast (notificação popup)

Notificação flutuante que aparece sobre o conteúdo. 4 cores semânticas e 2 temas (long, short). Container fixo no canto.

## Markup canônico

Veja `toast.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `toast.css` para as classes CSS deste componente.
