# Grid — celulas especiais

Variantes de célula com estrutura própria: produto (código + família + chips), estoque (com ícone unidades), PMC, preço vigente (com indicadores), preço concorrente, margem objetiva.

## Markup canônico

Veja `grid-cells.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `grid-cells.css` para as classes CSS deste componente.
