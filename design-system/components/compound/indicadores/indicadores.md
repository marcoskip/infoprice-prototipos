# Indicadores de competitividade

Badges semanticos com 5 níveis (muito-bom, bom, regular, ruim, muito-ruim). Cores derivadas dos tokens light de verde, laranja e vermelho.

## Markup canônico

Veja `indicadores.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `indicadores.css` para as classes CSS deste componente.
