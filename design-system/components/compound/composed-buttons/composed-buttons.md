# Botões compostos

Botões do cabeçalho com base (ícone) + drop (chevron) que abre dropdown. Variante <code style="font-family:'JetBrains Mono',monospace;font-size:13px">--solo</code> remove o drop. Estado <code style="font-family:'JetBrains Mono',monospace;font-size:13px">.is-selected</code> destaca em azul.

## Markup canônico

Veja `composed-buttons.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `composed-buttons.css` para as classes CSS deste componente.
