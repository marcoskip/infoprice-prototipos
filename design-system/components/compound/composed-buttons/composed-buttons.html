Botões compostos

Quando usar: SOMENTE no Cabeçalho de resultados, como botão icon-only de toolbar com dropdown opcional (variante --solo remove o drop). Estado .is-selected indica filtro ativo.
Quando NÃO usar: fora do Cabeçalho de resultados. Para botão com texto e dropdown em outros contextos, use Twin button. Para ações principais da página, use Button.

Botões do cabeçalho com base (ícone) + drop (chevron) que abre dropdown. Variante --solo remove o drop. Estado .is-selected destaca em azul.

Variantes (base+drop, solo, selected) 
<!-- Base + drop -->
<div class="composed-btn">
  <button class="composed-btn__base"><img src="..." alt="" /></button>
  <button class="composed-btn__drop" data-dropdown="dd-id">
    <span class="material-icons-outlined">keyboard_arrow_down</span>
  </button>
  <span class="composed-btn__tooltip">Texto do tooltip</span>
  <div class="composed-dropdown" id="dd-id"> ... </div>
</div>

<!-- Solo (sem drop) -->
<div class="composed-btn composed-btn--solo">
  <button class="composed-btn__base"><img src="..." alt="" /></button>
</div>

<!-- Selected (azul ativo) -->
<div class="composed-btn composed-btn--solo is-selected"> ... </div>
