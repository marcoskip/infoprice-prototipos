# MessageBox

Mensagem inline embutida em uma seção da página (não é popup). 4 cores semânticas: info, success, warning, error. Pode ter ícone, título, corpo e botão de ação.

## Markup canônico

Veja `message-box.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `message-box.css` para as classes CSS deste componente.
