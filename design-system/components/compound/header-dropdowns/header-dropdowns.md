# Header dropdowns

Dois dropdowns do header: produtos (acessado pelo menu quadrado azul) e usuário. Width 280px, radius 0 0 6px 6px no produto, radius padrão no usuário.

## Markup canônico

Veja `header-dropdowns.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `header-dropdowns.css` para as classes CSS deste componente.
