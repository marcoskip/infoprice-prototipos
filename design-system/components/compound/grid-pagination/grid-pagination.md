# Grid — paginação

Barra inferior do grid. Esquerda mostra itens por página + total, direita mostra navegação + botões de página. Página ativa em azul.

## Markup canônico

Veja `grid-pagination.html` — contém os snippets canônicos de cada variante (extraídos dos blocos `<pre><code>` do design-system.html).

## Estilos

Veja `grid-pagination.css` para as classes CSS deste componente.
