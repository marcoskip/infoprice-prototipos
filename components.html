Mapeamento rsuite

Cada componente do Design System mapeado para seu equivalente em rsuite v5/v6. Componentes sem equivalente direto estão marcados como custom.

Visão geral
Componente HTML rsuite Props principais Observação
.btn-primary <Button> appearance="primary" size="md" Cor vem do tema customizado
.btn-secondary <Button> appearance="subtle" size="sm" —
.btn-icon <IconButton> appearance="default" —
.btn-icon-blue <IconButton> appearance="subtle" color="blue" —
.btn-icon-red <IconButton> appearance="subtle" color="red" —
.btn-icon-row <IconButton> appearance="subtle" size="xs" width custom via style
.btn-clube <Button> color="orange" size="xs" —
.badge-sm <Tag> size="sm" color="blue|red|green..." —
.chip-badge <Badge> content={99} color="blue" Envolve o chip
.chip-default / .chip-active <Tag> closable onClose size="md" —
.filter-chip <SelectPicker> / <CheckPicker> size="sm" placeholder="..." Visual difere; pode precisar de custom trigger
.variation / .variation-sm <Tag> size="sm" color="red|green" + ícone via startIcon
.preco-input <Input> size="xs" style={{textAlign:'right'}} —
.preco-input-oferta <Input> size="xs" + style custom borderColor e background via style
.data-table <Table> hover bordered data={[...]} + Column + HeaderCell + Cell
input[checkbox] <Checkbox> color="blue" indeterminate indeterminate para select-all
.badge-lite custom — Styling muito específico do menubar
.tag-green custom — Pill com border-radius 12px, sem equivalente exato
.big-card-* custom — rsuite tem <Card> mas sem variantes de cor semântica
.preco-row custom — Layout par Regular/Oferta sem equivalente
.insight-icon custom — Pode usar <Avatar> como base
